This repository contains all 15 JavaScript lab assignments from the supplied BCS354 assignment document.

## Folder structure

Each `LabN` folder contains one `.js` file for each task, a `README.md`, and an `images/` folder for output screenshots. No HTML files are included.

## Running the programs

- For normal JavaScript tasks, open a terminal in the task folder and run `node Task1.js` (replace the filename as needed).
- Lab 9 Tasks 1, 3 and 4 use browser DOM and localStorage. Open the browser Developer Tools (F12), select Console, paste the contents of the relevant `.js` file and run it. The script creates its own page elements, so no separate HTML file is required.
- For timer and Promise tasks, wait for the asynchronous output to finish.

## Screenshots

Save the actual output screenshot for each task in that lab's `images/` folder using names such as `Task1.png`, `Task2.png`, etc. Screenshot files are placeholders for your own genuine output; they are not pre-generated.
